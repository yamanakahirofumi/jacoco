# JaCoCo XMLレポート スキーマ仕様

JaCoCoのXMLレポート形式（`report.dtd`）に基づいた、各要素と属性の仕様です。

## 基本構造

XMLレポートは、セッション情報、プロジェクトの構造（グループ、パッケージ、クラス、メソッド、ソースファイル）、および各レベルでのカバレッジ計測値（カウンター）で構成されます。

## 階層構造
- `report` (ルート)
  - `sessioninfo` (複数可)
  - `group` または `package` (複数可)
    - `group` (ネスト可)
    - `package`
      - `class`
        - `method`
          - `counter`
        - `counter`
      - `sourcefile`
        - `line`
        - `counter`
      - `counter`
    - `counter`
  - `counter` (ルートレベルの合計)

---

## 要素定義

### `report`
レポートのルートノードです。

| 属性 | 必須 | 説明 |
| :--- | :--- | :--- |
| `name` | はい | レポートの名前 |

### `sessioninfo`
実行データに寄与したセッションに関する情報です。

| 属性 | 必須 | 説明 |
| :--- | :--- | :--- |
| `id` | はい | セッションID |
| `start` | はい | セッション開始時のタイムスタンプ（ミリ秒） |
| `dump` | はい | データがダンプされた時のタイムスタンプ（ミリ秒） |

### `group`
プロジェクト構造内の論理的なグループ（モジュールなど）を表します。

| 属性 | 必須 | 説明 |
| :--- | :--- | :--- |
| `name` | はい | グループの名前 |

### `package`
Javaパッケージを表します。

| 属性 | 必須 | 説明 |
| :--- | :--- | :--- |
| `name` | はい | パッケージ名（VM表記：例 `org/jacoco/example`） |

### `class`
Javaクラスを表します。

| 属性 | 必須 | 説明 |
| :--- | :--- | :--- |
| `name` | はい | クラスの完全修飾名（VM表記：例 `org/jacoco/example/MyClass`） |
| `sourcefilename` | いいえ | 対応するソースファイル名 |

### `method`
クラス内のメソッドを表します。

| 属性 | 必須 | 説明 |
| :--- | :--- | :--- |
| `name` | はい | メソッド名 |
| `desc` | はい | メソッド記述子（引数と戻り値の型） |
| `line` | いいえ | メソッドの開始行番号 |

### `sourcefile`
ソースファイルを表します。

| 属性 | 必須 | 説明 |
| :--- | :--- | :--- |
| `name` | はい | ソースファイル名 |

### `line`
ソースファイル内の特定の行のカバレッジ情報です。

| 属性 | 必須 | 説明 |
| :--- | :--- | :--- |
| `nr` | はい | 行番号 |
| `mi` | いいえ | 未カバーの命令数 (missed instructions) |
| `ci` | いいえ | カバー済みの命令数 (covered instructions) |
| `mb` | いいえ | 未カバーの分岐数 (missed branches) |
| `cb` | いいえ | カバー済みの分岐数 (covered branches) |

### `counter`
各レベル（レポート、グループ、パッケージ、クラス、メソッド、ソースファイル）におけるカバレッジの統計値です。

| 属性 | 必須 | 説明 |
| :--- | :--- | :--- |
| `type` | はい | 指標のタイプ (`INSTRUCTION`, `BRANCH`, `LINE`, `COMPLEXITY`, `METHOD`, `CLASS`) |
| `missed` | はい | 未カバーの項目数 |
| `covered` | はい | カバー済みの項目数 |
